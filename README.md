# Alano DT 6 (alanodt6.com.pk)

Next.js marketing site for **Alano DT 6** — Dragon Tiger / casino APK guides for Pakistan.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS + Poppins
- Domain: `https://alanodt6.com.pk`

## Scripts

```bash
npm run dev
npm run build
npm start
```

## Brand config

Edit `src/lib/siteConfig.ts` for domain, download URL, version, ratings, and image paths.

## Images
